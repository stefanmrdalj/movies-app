# Movies App

Responsive movie discovery application built with React, TypeScript, MobX, and TMDB API.

## Features

- Trending movies and TV shows
- Movie and TV show details pages
- Trailer modal with YouTube integration
- Similar movies and TV shows
- Search functionality
- Responsive design for mobile, tablet, and desktop
- Animated loading screen
- Horizontal sliders and hover effects
- Ratings system

## Tech Stack

- React 19
- TypeScript
- Vite
- MobX
- React Router
- Axios
- SCSS / Sass
- Swiper.js
- Lottie React
- React Simple Star Rating
- TMDB API

## Installation

```bash
npm install
npm run dev
```

## Environment Variables

Create a `.env` file in the root directory:

```env
VITE_API_KEY=your_tmdb_api_key
```

Get your API key from:

https://www.themoviedb.org/settings/api
